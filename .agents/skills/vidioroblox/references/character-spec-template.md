# Canonical character specification

## Default character
- Type: original Roblox-inspired 2D block character.
- Head: square/block-shaped, large enough for readable facial expressions.
- Body: rectangular torso, block arms and legs, simple hands and feet.
- Face: two clear eyes, eyebrows, simple mouth; expressions must read at phone size.
- Linework: consistent dark outline; clean cel-shaded fills.
- Outfit: choose once per project and keep unchanged unless the story explicitly includes a costume change.
- Orientation: front, three-quarter, and side-facing variants where needed.
- Background: transparent.

## Consistency checklist
- Same head/body proportions in every shot.
- Same colors, clothing, accessories, outline width, and face design.
- No random changes to hairstyle, eye spacing, or limb length.
- Keep feet aligned with the 3D ground plane.
- Use matching lighting/shadow treatment so the character feels integrated without turning it into a fully 3D model.

## Animation states
Create only the states required by the story. Reuse them across shots:
- idle
- walk
- run
- talk
- look-left / look-right
- surprised
- sad / happy / angry as needed
- point / hold-prop as needed
